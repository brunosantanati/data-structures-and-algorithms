# 🧪 Python Unit Testing Guide

## 🐍 Requirements

- Python 3.x
- (Optional) `pytest` for easier test running

## ✅ How to Run Tests

### Option 1: Run directly with `python3`
```bash
python3 test_two_sum.py
```

### Option 2: Use unittest discovery
```bash
python3 -m unittest discover
```

### Option 3: Use `pytest`
```bash
pip install pytest
pytest
```
